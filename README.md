# Проект получения информации о вакансиях и компаниях с платформы hh.ru в России:
Приложение для получения и фильтрации вакансий

## В проекте реализованы функции:
* в модуле hh_api реализован класс HHParser, который получает 
  список топ-10 работодателей и их вакансий с сайта hh.ru
* в модуле utils реализованы функции работы с базой данных:
  - ее создание
  - создание в ней таблиц и 
  - заполнение таблиц данными с сайта hh.ru
* в модуле db_manager реализован класс методов работы с данными в таблицах БД"

* в модуле main реализована логика проекта, включая взаимодействие с пользователем

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/DB_vacancies.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```

3. Создайте файл database.ini и заполните его своими данными 
   из примера этого файла для работы с БД postgresql
